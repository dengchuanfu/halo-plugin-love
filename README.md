# Halo 情侣主页插件

`love-page-plugin` 是一个无需数据库的 Halo 插件，用于提供公开的情侣纪念页面。启用后可通过 `/love` 访问。

插件 ID：`PluginLove`。

## 功能

- 提供自适应全屏的情侣主页，桌面端与移动端均可完整展示。
- 页面包含自定义壁纸、情侣头像与昵称、动态爱心、波浪过渡和相恋时长计时器。
- 后台可分别配置两人的名字、QQ 号、头像图片链接、上传头像、头像点击跳转链接、相恋日期、页面标题、纪念文案及自定义壁纸。
- 左右头像来源互不影响，可分别使用 QQ 号、图片链接或上传头像；每一侧的优先级均为：QQ 号、头像图片链接、上传头像。
- 未配置头像时，左右两侧均使用插件内置默认头像，不请求外部站点。
- 未填写相恋日期时，插件会按当前服务器日期自动回推 520 天；填写真实日期后则按该日期正常累计。
- 设置头像点击跳转链接后，点击对应头像会在新标签页打开该链接。
- 未上传头像或壁纸时，自动使用插件内置的默认资源；外部头像或壁纸地址不可用时，头像回退为内置默认头像，壁纸回退为页面底色。
- 配置保存在 Halo 插件的 ConfigMap 中；插件不向自建第三方服务传输数据。

## 外部服务与隐私说明

- QQ 头像：填写 QQ 号后，访客浏览器会直接向腾讯 QQ 头像服务 `q1.qlogo.cn` 请求头像。请求会包含填写的 QQ 号，并可能包含浏览器正常发送的 IP 地址、User-Agent、Referer 等网络元数据；插件不会在服务器端保存或转发这些信息。
- 关闭方式：清空对应的 QQ 号，改用上传头像或头像链接即可停止 QQ 头像请求。头像链接仅在用户主动填写后使用，图片请求由访客浏览器直接发往所填写的地址。
- 外部资源不可用时：头像 `<img>` 加载失败会自动切换到插件内置默认头像；自定义壁纸加载失败时保留页面底色，不影响计时器和其他页面功能。

## 使用方式

1. 在 Halo 后台的“插件”页面上传并启用插件。
2. 打开插件详情页的“设置”，填写情侣资料并保存。
3. 访问 `https://你的域名/love` 查看页面效果。

## 本地开发

项目要求使用 JDK 21。进入项目目录后运行：

```bash
./gradlew build
```

构建产物位于 `build/libs/`，可在 Halo 后台上传安装。
